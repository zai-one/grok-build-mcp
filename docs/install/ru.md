# Install (Русский)

> Unofficial community project — not xAI / Grok.

Только простой путь. Полная инструкция: **[EASY.md](../EASY.md)** (EN).

```bash
curl -fsSL https://raw.githubusercontent.com/zai-one/grok-mcp/main/scripts/install.sh \
  | bash -s -- --project "$HOME/code/my-project"
grok login
```

Затем self-test и JSON из `~/.config/grok-mcp/mcp/`. Неофициальный проект (не xAI/Grok).

Опционально (документы на английском): [VPS / HTTP](vps.md) · [FastMCP](fastmcp.md).
