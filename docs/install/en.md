# Install (English)

> Unofficial community project — not xAI / Grok.

**This is the install path.** Full page: **[EASY.md](../EASY.md)**.

```bash
curl -fsSL https://raw.githubusercontent.com/zai-one/grok-mcp/main/scripts/install.sh \
  | bash -s -- --project "$HOME/code/my-project"
```

Then `grok login` → self-test → merge `~/.config/grok-mcp/mcp/*.json` into Claude/Cursor.

Manual pip/venv steps are **removed** from public docs on purpose.
