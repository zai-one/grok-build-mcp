# Audits

One file per audit slice, written by an independent agent that only reads.

Prompts live in `D:\ZAI\.tasks\2026-08-17-grokmcp-audit-*.md`. Slices are
deliberately disjoint so the agents can run at the same time without fighting
over the same files: security, receipt truthfulness, concurrency, host contract,
test quality, platform and docs.

A finding here is a claim awaiting triage, not an agreed defect. Read it, decide,
and record what you did with it -- an audit nobody answers is worse than none,
because it looks like coverage.
