# Пять скептиков против этого репозитория, 2026-08-19

Пять job'ов через сам мост, роль `skeptic`, разрешённые команды `pytest`,
`git log/ls-files/diff/show`. Четыре дошли до конца (`completed`), пятая
(`lifecycle`) упёрлась в мой таймаут 900 с и отчёта не дала.

Важно само по себе: **ни одного `ACP_STOP_cancelled`, ни одного
`ACP_OUTPUT_LIMIT`**. Утром такие job'ы умирали за 30 секунд, не оставляя
ничего.

Ниже — что скептики заявили и что из этого я **воспроизвёл**. Отчёт агента
доказательством не считается: половина заявленного подтвердилась, часть
осталась непроверенной, и это разные вещи.

## Подтверждено и исправлено (0.18.0)

| Находка | Как проверял |
|---|---|
| `git add -A` кладёт в lane чужие файлы | посмотрел коммиты soak-прогонов: `__pycache__/*.pyc` и `outputs/ads/logs/runtime.log` внутри `grok/*` |
| `SECRET_KEY=`, `AWS_SECRET_ACCESS_KEY=` не редактируются | прогнал `redact_text` на каждой пробе |
| `{"api_key":…}`, `{"client_secret":…}` не редактируются | то же |
| `Authorization: Basic <b64>` теряет только слово `Basic` | то же |
| `PASSWORD="a b c"` — утекает хвост после первого пробела | то же |
| `redis://:pass@host` (пустой пользователь) не редактируется | то же |
| `postgres://u:pa@ss@host` — утекает хвост после первого `@` | то же |
| `sk_live_…` (подчёркивание, не дефис) не редактируется | то же |

## Проверено 2026-08-20 (0.19.0)

Каждая находка ниже прогонялась зондом. Пять подтвердились и исправлены, одна
не подтвердилась, две остались осознанно.

| Находка | Вердикт |
|---|---|
| `auth.json.` / `.env::$DATA` мимо denylist | **подтверждено**, исправлено |
| `start_job` оставляет зомби `running` | **подтверждено**, исправлено |
| Гейт не смотрит на `lane_commit` | **подтверждено**, исправлено |
| `C:secret.py` проходит гейт команд | **подтверждено**, исправлено |
| `unknown`-запись читается как replay | **подтверждено**, исправлено |
| Хвостовой пробел `.. \out.txt` | **не подтвердилось**: `resolve()` снимает пробел так же, как Win32 |
| Коммит lane до вердикта | подтверждено, оставлено намеренно |
| lane двумя написаниями (`foo` / `grok/foo`) | подтверждено, не исправлено |

Два первых вердикта были ложными: зонд C1 звал `start_job` с неверной
сигнатурой и ловил свой же `TypeError`, зонд G1 сравнивал первое текстовое
вхождение имён в функции с дюжиной ранних возвратов. **«Не воспроизвелось»
требует такой же проверки, как «подтверждено».**

## Что скептики честно назвали неломающимся

`_job_id` (разные пакеты расходятся, один пакет — один воркер); PEM во всех
формах; `postgres://user:pass@host`; голые `xai-`/`ghp_`/`AKIA`/JWT; обычный
`..`, UNC, абсолютный путь снаружи; junction/symlink через `resolve()`;
`paths_equal` / `path_in_allowlist`; юникод, похожий на разделитель; уже
лежащий артефакт, который этот запуск не трогал; подмена теста воркера —
runtime перезаписывает `tests` своим прогоном.

## Чего скептики не нашли, а нашёл прогон

Собственная правка редактора дала **катастрофический бэктрекинг**: одна строка
диффа 34 мс вместо 0.19, набор тестов 2 часа 10 минут вместо двух минут — и всё
это время зелёный. Поймано по времени, а не по красному тесту. Причина: два
безграничных квантификатора вокруг альтернации. Переписано на линейный проход,
добавлены два теста на стоимость.

Исходные отчёты скептиков: `scratchpad/sweep/*.md` (эфемерны, в репозиторий не
коммитятся).
